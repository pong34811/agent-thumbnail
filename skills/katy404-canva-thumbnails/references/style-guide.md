# คู่มือสไตล์และองค์ประกอบปกคลิป VTuber ไทย (Thai VTuber Style Guide)

เอกสารอ้างอิงภาษาภาพ องค์ประกอบ และมาตรฐานงานออกแบบปกคลิปสำหรับ VTuber ไทย โดยสังเคราะห์จากงานจริงใน `outputs/` (`aomi-debut-20260731`, `tygarina-20260801`) และภาพต้นแบบมาตรฐาน ([thai-vtuber-layout-guide.png](previews/thai-vtuber-layout-guide.png), [thai-vtuber-example-chuey-duay.jpg](previews/thai-vtuber-example-chuey-duay.jpg))

## 1. การวิเคราะห์ภาพต้นแบบมาตรฐาน (Visual Blueprint Analysis)

### 📌 กรณีศึกษา: ปก "ช่วยด้วย! ติดอยู่คนเดียว"
![ตัวอย่างปก VTuber ไทย](previews/thai-vtuber-example-chuey-duay.jpg)

1. **การดึงดูดทางอารมณ์ (Emotional Urgency):**
   - ตัวละครกำลังตื่นตระหนกสุดขีด: ตาเบิกกว้าง น้ำตาคลอ เหงื่อแตก ปากสั่นอ้า มือถือแท่งไฟ
   - การสื่อสารทางอารมณ์เกิดขึ้นทันทีในเสี้ยววินาที ทำให้คนดูเกิดความสงสัย (Curiosity Gap) ว่า "เกิดอะไรขึ้นในถ้ำ?"
2. **การจัดวางแบบ Half-body (ครึ่งตัว):**
   - ตัวละครกินพื้นที่เกือบ 50% ของความกว้าง และสูงจากขอบล่างจรดเกือบขอบบน
   - เห็นรายละเอียดเสื้อผ้า หน้าอก เครื่องประดับ และท่าทางมือชัดเจนโดยไม่เสียพื้นที่ให้ช่วงขา
3. **เส้นขอบขาวเรืองแสง (Glowing White Outline):**
   - เส้นขอบสีขาวคมชัดล้อมรอบทั้งโมเดล เส้นผม หู และแท่งไฟ
   - มีเงาดำนุ่มรองหลังเส้นขอบขาว ทำให้โมเดลลอยเด่นออกมาจากพื้นหลังถ้ำที่มืดสลัว
4. **ลำดับขั้นข้อความ (Text Hierarchy):**
   - บรรทัดบน (Hook หลัก): **"ช่วยด้วย!"** — สีแดงสด ฟอนต์หนาไม่มีหัว ขนาดมหึมา ขอบดำหนา
   - บรรทัดล่าง (บริบทเสริม): **"ติดอยู่คนเดียว"** — สีขาวล้วน ขนาดรองลงมา ขอบดำหนา
   - ใช้เพียง 2 วลีสั้น รวม 4 คำ อ่านจบได้ในพริบตาเดียว

## 2. โครงสร้างผังองค์ประกอบ 16:9 (Layout Anatomy)

![ผังจัดวางปก 16:9](previews/thai-vtuber-layout-guide.png)

| องค์ประกอบ | สัดส่วน / ขนาด | ตำแหน่ง | หน้าที่ / กฎสำคัญ |
|---|---|---|---|
| **โซนข้อความ Hook** | กว้าง 50% ซ้าย | ซ้ายกลาง (x: 80–950, y: 450–650) | สูงสุด 3–5 คำ, Hook แดงใหญ่ + รองขาวเล็กกว่า, ขอบดำหนา + เงา |
| **ตัวละคร VTuber** | กว้าง 40–60% ขวา, สูง 85–95% | ขวา (ชิดขอบล่างของภาพ) | ต้องเป็น **"ครึ่งตัว" (Half-body)** เท่านั้น, มีขอบขาวหนา 12–16px |
| **พื้นหลัง (Background)** | เต็มพื้นที่ 1920×1080 | ชั้นล่างสุด | ดึงจากเฟรมคลิปจริง, เบลอ 35–45px, ลดแสง 40–45%, ไล่เฉดมืดฝั่งซ้าย |
| **โซนปลอดภัย (Safe Zone)** | กว้าง ~25%, สูง ~20% ขวาล่าง | มุมขวาล่าง | **ห้ามวางข้อความสำคัญหรือจุดโฟกัส** เพราะกล่องเวลา YouTube ทับ |

## 3. ตารางเปรียบเทียบ: ข้อควรทำ VS ข้อห้ามทำ

| หัวข้อ | ✅ แนวทางที่ถูกต้อง (High-CTR) | ❌ ข้อผิดพลาดที่ต้องเลี่ยง |
|---|---|---|
| **ขนาดตัวละคร** | **ครึ่งตัว (Half-body)** หัวถึงเอว/กระโปรง ขนาดใหญ่เต็มตา สีหน้าและแววตาชัดเจน | **เต็มตัวย่อส่วน (Full-body)** ตัวเล็กจิ๋ว มองไม่เห็นสีหน้าบนจอมือถือ |
| **เส้นขอบตัวละคร** | เส้นขอบขาวหนา (12–16px) + เงานุ่ม ตัดขาดจากพื้นหลัง | ไม่มีขอบ หรือขอบบางกลืนไปกับสีพื้นหลัง |
| **การจัดการไฟล์โมเดล** | ตรวจสอบและลบเม็ดพิกเซลลอย (Stray pixels) ก่อนทำขอบขาว | ปล่อยให้มีขอบขาวเป็นเกาะลอยอยู่กลางอากาศ |
| **ข้อความ** | สั้นกระชับ 3–5 คำ, Hook แดงเด่น + รองขาวขยายความ | ยาวเป็นประโยคบทพูด หรือทวนชื่อคลิปยาวๆ |
| **สีข้อความ** | แดงเฉพาะ Hook หลัก, ขาวสำหรับข้อความรอง | แดงทุกคำจนไม่มีจุดเด่น หรือใช้สีเหลือง/ฟ้าตัดกันมั่วซั่ว |
| **ฟอนต์** | Mitr Bold หรือฟอนต์ไทยไม่มีหัวทรงหนา ขอบดำหนา | ฟอนต์บาง, ฟอนต์มีหัวทางการ, หรือไม่มีขอบดำกลืนกับฉาก |
| **มุมขวาล่าง** | ปล่อยว่าง หรือให้เป็นเพียงช่วงเอว/เสื้อผ้าด้านล่างของตัวละคร | วางข้อความสำคัญหรือหน้าตัวละครไว้มุมขวาล่าง โดนเวลาคลิปทับ |
| **พื้นหลัง** | มีความลึก บรรยากาศมืด/เบลอ มีเกรเดียนท์มืดรองรับตัวอักษร | พื้นหลังขาว/สว่างจ้า, มีตัวหนังสือเก่าอ่านออกแย่งสายตา |

## 4. มาตรฐานปก YouTube Shorts (9:16 Portrait)

1. **สัดส่วน:** 1080×1920 px
2. **การวางตัวละคร:** กึ่งกลางแนวนอน (Center x=540) ลำตัวส่วนล่างชนขอบล่าง สูงประมาณ 1100–1200px
3. **การวางข้อความ:** กึ่งกลางแนวนอน ในช่วง 1/3 บนของหน้าจอ (y=300–550)
4. **การเว้นระยะ Safe Zone:**
   - ขอบขวา: เว้นพื้นที่อย่างน้อย 150px สำหรับไอคอน Like, Comment, Share, Remix
   - ขอบล่าง: เว้นพื้นที่อย่างน้อย 400px สำหรับชื่อช่องและข้อความบรรยาย Shorts
5. **แสงและเฉดเงา:** ทำ Dark Gradient ด้านบน เพื่อให้ข้อความสีขาว/แดงอ่านง่ายบนทุกอุปกรณ์
