### 2.2 กฎการจัดวางตัวอักษร (Typography Rules)
* **ฟอนต์หลัก:** `Mitr Bold` (OpenType via RAQM Engine)
* **Primary Hook:**
  * สีแดงสด `#EC1C24` หรือสีเหลืองทอง `#FFE600`
  * เส้นขอบสีดำหนา (Stroke ratio: 8–10% ของขนาดฟอนต์)
  * Soft Drop Shadow: Offset `(6, 9)`, Blur `7px`, ความโปร่งแสง `0.80`
* **Secondary Context:**
  * สีขาวบริสุทธิ์ `#FFFFFF` ขอบดำหนา
* **การซ้อนบรรทัด (Ink Bounding Box Stacking):**
  * คัดแยกสระ/วรรณยุกต์ติดหาง tall consonants (`ป, ฝ, ฟ`) และสระหน้า (`ไ, ใ, โ`) ด้วย `MIN_GAP = 0.05 em` เพื่อไม่ให้ Stroke กลืนตัวอักษร

## 3. การประมวลผลฉากหลัง (Background Processing Rules)

### 3.1 ฉากสไลด์และคุยเล่น (Zatsudan / Story Slides)
สไลด์นำเสนอหรือภาพสตอรี่บอร์ดของ Aomi มักมีตัวหนังสือบรรยายขนาดใหญ่อยู่แล้ว หากไม่เบลอจะเกิดปัญหาตัวหนังสือตีกัน
* **การตั้งค่าเฉพาะ:**
  * Gaussian Blur: **46–60px**
  * หรี่แสง (Brightness): **0.50** (ลดแสงลง 50%)
  * เร่งสี (Color Saturation): **1.15x**
  * ผลลัพธ์: ฉากหลังกลายเป็น Ambient Glow สวยงาม ไม่มีตัวหนังสือเก่าให้อ่านออก

### 3.2 ฉากเกมเพลย์สด (Gameplay Footage)
* คงความคมชัด **0px blur** เสมอ
* **Clean Crop ป้องกันตัวละครซ้อน (กฎเหล็ก):** สตรีมสดที่มีกล้อง Live Facecam ($x \in [0, 480], y \in [450, 1080]$) และแถบโดเนท/Hotbar ด้านล่าง ให้ทำการ Clean Crop เจาะเฉพาะโซนเกมเพลย์ `(540, 0, 1920, 776)` (สัดส่วน 16:9 พอดีเป๊ะ) แล้ว resize เป็น 1920×1080 ได้ฉากหลังเกมเพลย์ 100% คมชัด 0px blur ไร้สิ่งรบกวน
* ใส่ Dark Gradient Mask จากซ้ายไปขวา (`fade_start_x: 100`, `fade_end_x: 1150`, `max_alpha: 0.68`) เพื่อรองรับตัวหนังสือฝั่งซ้าย

## 5. การจัดเลย์เอาต์ (Layout Specifications)

### 5.1 ปกแนวนอน 16:9 (1920×1080)
* **โมเดล VTuber:** วางฝั่งขวา (`h ≈ 960–980px`), 5-layer separation ขอบขาว 12px + Drop Shadow
* **การยึดฐาน:** จมทะลุขอบล่าง `target_bottom = 1115px` หลบ Timestamp มุมขวาล่าง
* **ข้อความ:** วางฝั่งซ้าย `(90, 360)` ด้วย `anchor="ls"` (Left-baseline) ห้ามใช้ `anchor="ms"`
* **สีข้อความ:** Hook หลักแดง `#EC1C24` หรือทอง `#FFE600` (ขอบดำ 8%), รองขาว `#FFFFFF` (ขอบดำ 8%)

### 5.2 ปกแนวตั้ง 9:16 Shorts (1080×1920)
* **Shorts 3-Tier Architecture:**
  1. **Ambient Background:** ขยายฟุตเทจเต็มจอ + Gaussian Blur 36px + Darken 0.50 + Saturate 1.15
  2. **Center Gameplay Panel:** กรอบไฮไลต์เกมเพลย์ $1080 \times 612\text{px}$ ที่ $y = 590\text{px}$ ขนาบด้วยเส้นขาวบน-ล่าง
  3. **Large Centered Avatar:** ขนาดใหญ่เด่น $h \ge 1260\text{px}$, จัดกึ่งกลางที่แกน $x = 540\text{px}$, จมทะลุขอบล่าง `target_bottom = 1960px` ไม่ลอยเคว้ง
* **Safe Zone Typography:** กึ่งกลางแกน $x = 540\text{px}$ ด้วย `anchor="ms"` ที่ $y = 350\text{px}$ หลบ UI ล่าง 25% และขวา 15%
