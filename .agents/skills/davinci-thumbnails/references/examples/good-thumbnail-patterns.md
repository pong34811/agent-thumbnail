# ตัวอย่างและแบบแผนของปก VTuber ที่ดี

เอกสารนี้รวม **หลักที่ถ่ายโอนได้** จากปกที่ผู้ชมนิยม และเกณฑ์ตรวจว่า "ปกที่ดี" หน้าตาเป็นอย่างไร ไม่ได้เก็บภาพหรือ asset ของใครไว้ ภาพต้นแบบที่เก็บไว้ในสกิลคืองานของผู้ใช้เอง ([tygarina-v7.md](tygarina-v7.md)) และ preview ที่ระบุสิทธิ์ไว้แล้วใน `previews/` ห้ามลอกงานหรือ asset ของศิลปินคนอื่นมาใช้

## 1. ข้อสังเกตจากปก VTuber ไทยที่ยอดนิยม (ตรวจ 2 ตุลาคม 2026)

แหล่ง: หน้าผลค้นหา YouTube "vtuber ไทย ไฮไลท์" เรียงตามยอดวิว ดูภาพปกด้วยตาเพียง 3 รายการแรก (ที่เหลืออ่านจากชื่อ/ช่อง/ยอดวิว) **ไม่ได้ตรวจ CTR และไม่สรุปว่าปกเป็นเหตุของยอดวิว** ยอดวิวอาจมาจากตัวคลิป ช่อง หรือระยะเวลาที่เผยแพร่

| คลิปที่ดู (ชื่อตามที่แสดง / ช่อง / ยอดวิวตอนตรวจ) | สิ่งที่เห็นบนปก (ถ่ายโอนเป็นหลักการ ไม่คัดลอก) |
|---|---|
| "【Thai Vtuber】เจ้าโดเนทตัวร้าย…" / MonoSky / 508K | ตัวละครหลายตัวเรียงหน้ากระดาน ข้อความไทยตัวใหญ่ขอบหนาหลายสี พื้นหลังสว่าง |
| "@PyorkThePork sings so well…" / ตื่นมาแปล / 290K | ใบหน้าตัวละครใหญ่เกินครึ่งเฟรม ข้อความสั้น "ร้องเพราะจนโดนเปย์" + ตัวเลขใหญ่มาก ("40,000") สีสดตัดกับพื้น |
| "Brother, please send me the dolphin." / Eileennoir Ch. / 189K | ภาพ chibi/ใบหน้าใหญ่ การ์ตูนสีสด คำอุทานไทยหนาเป็นหัวข้อ |

**หลักที่ถ่ายโอนได้:**

1. **ข้อความสั้นและใหญ่มาก** (1–3 คำ) กินพื้นที่ราว 30–40% ของเฟรม ขอบหนา อ่านออกที่ขนาดเล็ก
2. **ใบหน้า/ตัวละครใหญ่และใกล้** สีหน้าอ่านออกทันที
3. **พื้นหลังสดและสะอาด** ไม่เป็นเทาทึบ ไม่รกจนแย่งตัวละคร
4. **ตัวเลข/ข้อเท็จจริงเดียวที่กระตุ้นความอยากรู้** เช่น จำนวนเงิน (ใช้เฉพาะเมื่อมีจริงในคลิป)
5. **หนึ่งปก หนึ่งไอเดีย** ไม่เล่าหลายเรื่องพร้อมกัน

หลายช่องใช้ข้อความหลายสี ซึ่งเป็นเอกลักษณ์ของช่อง ในโปรเจกต์นี้ยังคงกฎ hook แดง + รองขาวตามสกิล

## 2. เกณฑ์ "ปกที่ดี" (สรุปจากการ QC 25 ข้อและชุด Tygarina v7)

ปกที่ดีต้องผ่านทุกข้อก่อนส่งงาน:

- **เข้าใจใน 1–2 วินาที:** บอกได้ว่าเรื่องอะไรจากตัวละครกับ hook เท่านั้น
- **Hook สอดคล้องหลักฐานจาก subtitle/เฟรมจริง** ไม่เกินจากสิ่งที่พูดในคลิป ไม่ใช้ชื่อ Timeline เป็น hook โดยไม่ตรวจ
- **ตัวละคร:** ใบหน้าเห็นชัด ไม่ถูกข้อความบัง สีหน้าแรงพอและต่างจากปกอื่นในชุด ขอบตัดสะอาด ซูมดูมือ ปลายผม และขอบขาวแล้ว
- **ภาษาไทย:** สะกดถูก เว้นวรรคให้อ่านไม่เพี้ยน (เช่น "ขอ งับหู") ใช้คำตามที่พูดจริง (เช่น "ผู้หญิง" ไม่ใช่ "ผู้สาว") สระ/วรรณยุกต์ไม่จมในขอบดำ
- **ลำดับภาพ:** hook แดงใหญ่กว่าข้อความรองขาวชัดเจน รองขาวยังอ่านออกที่ 320×180
- **องค์ประกอบเสริมมีหน้าที่:** `!`/`?`/วงกลมใส่เมื่อมีหลักฐานเท่านั้น ห้ามซ้ำหน้าที่ (เช่น `!` ซ้ำกับ hook ที่ลงท้าย `?!`)
- **แยกจากปกอื่นในชุด:** ท่า สีหน้า พื้นหลัง หรือสีเรืองต่างกันพอให้แยกในฟีดได้
- **Safe Zone:** ไม่มีใบหน้าหรือข้อความสำคัญที่มุมขวาล่าง (Duration Badge); แนวตั้งไม่มีข้อความเหนือ y≈285 หรือเกิน x≈920
- **ผ่านทดสอบ:** 320×180 / 180×320, ขาวดำ, หรี่ตา (เห็นก้อนใหญ่ 2–4 ก้อน)

## 3. แม่แบบ A / B / C เมื่อต้องเสนอ concept ใหม่

ใช้เมื่อปกปัจจุบันยังอ่อนและต้องคิดทางเลือก (เขียนให้ลงมือทำใน Photoshop/Canva หรือ pipeline Python ได้ทันที):

- **A — Character / Emotion:** ใบหน้าใหญ่ครึ่งตัว สีหน้าสุดขั้วตรงจุดไคลแมกซ์ hook 1–3 คำสีแดงด้านซ้าย พื้นหลังสะอาดมีแสงเรืองสีเดียว
- **B — Story / Situation:** มีวัตถุหรือเหตุการณ์ที่เกิดจริงในคลิป (วงกลมพู่กันสีแดง `#EC1C24` ชี้จุดเกิดเหตุ) อวาตาร์ขนาดกลางมองไปยังจุดนั้น
- **C — Minimal High-Impact:** hook ตัวใหญ่ที่สุดบนพื้นเรียบ อวาตาร์ครึ่งตัวมุมขวา ไม่มีองค์ประกอบอื่น

เลือกแบบที่หลักฐานในคลิปสนับสนุนที่สุด ไม่ตัดสินจากความสวยอย่างเดียว
